# Credit Banking Project — Financial Risk & Loan Default Prediction

End-to-end exploratory data analysis (EDA), predictive risk modeling, and financial credit scoring on retail banking datasets.

Developed by **Aadarsh Sinha** ([@Monarch666](https://github.com/Monarch666)).

---

## 📊 Project Scope

- **Credit Scoring & Default Modeling**: Multivariate classification identifying high-risk borrowers using demographic, income, credit history, and loan characteristics.
- **Feature Engineering & Imputation**: Weight of Evidence (WoE), Information Value (IV), outlier mitigation, and categorical encoding.
- **Evaluation Metrics**: ROC-AUC curves, confusion matrices, precision-recall trade-offs, and KS statistics.

---

## 🚀 Environment Setup

### Using pip
```bash
# Clone the repository
git clone https://github.com/Monarch666/Credit-Banking-Project.git
cd Credit-Banking-Project

# Create virtual environment
python -m venv venv
venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Launch JupyterLab
jupyter lab
```
